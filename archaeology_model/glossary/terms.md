# 术语表

## 遗迹

| 术语 | 含义 |
|---|---|
| 灰坑 | H，人工填土坑，常含陶片等遗物 |
| 墓葬 | M，埋人遗骸的遗迹 |
| 探方 | T，发掘的基本单位 |
| 房址 | F，房屋遗迹 |
| 灶 | Z，用火遗迹 |
| 沟 | G，长条形遗迹 |

## 关系

| 术语 | 含义 |
|---|---|
| 打破关系 | 晚期遗迹破坏早期遗迹 |
| 叠压关系 | 晚期堆积覆盖在早期堆积之上 |
| 打破 | 年代晚的单位破坏年代早的单位 |
| 叠压 | 年代晚的单位压盖年代早的单位 |

## 器物

| 术语 | 含义 |
|---|---|
| 鬲 | 三足炊器 |
| 豆 | 高圈足食器 |
| 罐 | 储盛器 |
| 鼎 | 三足或圜底烹食器 |
| 盉 | 调酒或注水器 |

## 分析方法

| 术语 | 含义 |
|---|---|
| 类型学 | 按器物形态演变排序分期 |
| 地层学 | 按堆积上下关系判断年代早晚 |
| 随葬品组合 | 同墓共出器物的固定搭配 |
| 分期 | 把遗址遗存划分为若干年代段 |
| 断代 | 判断遗迹或遗物的具体年代 |
