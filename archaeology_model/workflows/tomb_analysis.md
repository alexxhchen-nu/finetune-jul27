# 墓葬分析流程

分析一座墓葬时按以下顺序进行。

## 1. 提取基本信息

- 墓葬编号
- 墓葬形制（竖穴土坑墓、洞室墓等）
- 墓向
- 开口层位
- 打破/叠压关系

## 2. 提取随葬品

- 器物名称
- 数量
- 摆放位置
- 组合关系

## 3. 查找地层证据

- 该墓被哪个单位打破
- 该墓打破哪个单位
- 同层位其他遗迹

## 4. 查找类型学资料

- 同类器物在区域分期中的位置
- 同组合墓葬的常见年代
- 报告作者的年代意见

## 5. 综合判断

- 列出事实
- 列出推断
- 列出不确定性
- 给出结论等级

## 6. 输出格式

```text
结论：...
依据：...
不确定性：...
结论等级：...
```
