# 引用规则

## 引用格式

每条引用包含三个要素：

```text
来源名称 + 具体位置 + 原文内容
```

示例：

```text
《XX遗址发掘报告》，第123页，M12为竖穴土坑墓，墓向180°。
```

## 引用类型

1. **直接引用**：原文措辞，用引号标出。
2. **概括引用**：用自己的话概括，必须注明来源和页码。
3. **对比引用**：并列多个来源时，分别标注每条出处。

## 禁止行为

- 不标注来源就下结论。
- 把模型推断包装成报告原文。
- 混合多个遗址的资料而不说明。

## 输出格式

回答中引用用 `[1]`、`[2]` 编号，末尾列出完整出处。
